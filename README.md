# FablePixel

A procedural pixel-art sprite generator that runs entirely in your browser — no accounts, no API keys, no servers. Every sprite is generated by deterministic algorithms from a seed, so the same seed always produces the same sprite, and any sprite can be shared as a link.

## Features

- **Three sprite categories:** characters/creatures, terrain tiles, and items & props (11 archetypes: sword, potion, shield, gem, coin, ring, key, chest, staff, axe, bow — plus organic blobs)
- **Three viewpoints:** top-down (Zelda/Pokémon style), isometric (diamond tiles with extruded faces), and side view (platformer style)
- **Era looks:** 8-bit, 16-bit, and 32-bit presets controlling shade count, dithering, outlines, and detail density
- **8 built-in palettes:** NES, Game Boy, Commodore 64, CGA, PICO-8, Endesga 32, AAP-64, Resurrect 64
- **Sizes:** 16×16, 32×32, 64×64, or any custom size from 8 to 128
- **Deterministic seeds:** reproducible sprites, shareable via URL
- **Seamless terrain:** square tiles wrap perfectly by construction (wrapped value noise)
- **Export:** single PNG, 16-sprite spritesheets (or a shift-click selection), at 1×/2×/4×/8× scale

## Usage

```bash
npm install
npm run dev       # local dev server
npm test          # engine test suite
npm run build     # production build (dist/)
```

Pick a type, view, era, palette, and size — then hit **Generate**. Click a variation to preview it, shift-click variations to build a custom spritesheet, and use the export bar to download PNGs.

## Architecture

- `src/engine/` — the pure generation engine: no DOM, no React. Seeded PRNG with forked per-stage streams, a palette-indexed pixel grid, ramp extraction from any palette, and a shared pipeline (regions → colorize → shade → dither → outline → cleanup) with pluggable per-category generators.
- `src/render/`, `src/export/` — the only DOM-adjacent code: canvas drawing, PNG encoding, spritesheet packing (packing/scaling math is pure and tested).
- `src/ui/` — React + zustand interface.

Because the engine is pure, the whole test suite runs headless in Node — determinism, palette integrity, outline invariants, tile seamlessness, and golden-sprite drift alarms.

## Deploying

Pushes to `main` deploy to GitHub Pages automatically via `.github/workflows/deploy.yml`. One-time setup: in the repository settings, set **Pages → Source** to **GitHub Actions**.
